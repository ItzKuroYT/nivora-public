A QUICK HEADS-UP

Before you install.

Windows releases are currently unsigned. Windows may show an unknown-publisher or SmartScreen prompt. Check that you downloaded from Nivora’s official GitHub release and compare the checksum when needed.

Windows setup installs Nivora and its uninstaller. The portable build runs without installation but still stores its profile in Windows AppData. Automatic updates are available in installed builds.
